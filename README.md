# AIHub

Agent Intelligence Hub 的公开静态站点。

网站：https://haotsi.github.io/AIHub/

内容由本地维护系统生成的公开快照提供，保留来源、时间、更新分类与可信度。此仓库只保存经过白名单与密钥检查的静态发布文件；不包含 API Key、数据库、个人额度、私人备注或本机 AA/Reset 受限缓存。模型和 Reset 页面提供当前可公开的功能及原站入口。

GitHub Pages 使用 main 分支根目录，.nojekyll 关闭 Jekyll 处理。后续更新应重新生成并验证本地发布包，再同步公开产物；本次发布没有新增周期性推送任务。

发布清单与内容指纹见 publication-manifest.json。
